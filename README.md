# powertoys-shortcut-search

A Microsoft PowerToys Command Palette extension to search and trigger Windows, PowerToys, and application-specific keyboard shortcuts.

## Quick Start

Build the solution:
```powershell
dotnet build shortcut_search.sln -p:Platform=x64
```

For full documentation, architecture details, and deployment steps, see [`shortcut_search/README.md`](shortcut_search/README.md).
